# BusDirect - Gestion des Réservations de Places
# Contexte du projet :
La compagnie de transport BusDirect souhaite digitaliser la gestion des réservations de sièges sur sa ligne interurbaine Safi → Marrakech.

L’agent de réservation doit pouvoir visualiser en temps réel le plan de la cabine et gérer l’attribution des places selon les disponibilités.

L’objectif est de concevoir une interface interactive permettant de :

Visualiser le plan de la cabine (20 places totales),
Réserver une place pour un passager (sur un siège choisi ou automatiquement sur le premier siège libre),
Modifier une réservation existante (changer le nom du passager et/ou le déplacer vers un autre siège libre),
Supprimer une réservation pour libérer immédiatement le siège,
Distinguer clairement par un code couleur l’état des sièges (Libre et Occupé).
Ce projet permet de consolider les compétences en manipulation du DOM, synchronisation de listes déroulantes dynamiques, gestion des événements JavaScript, validation de formulaires et conception d’une interface responsive.
